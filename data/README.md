# 数据目录

当前语料由用户换源提供，共六份，文件为 `raw/199801.txt` 至 `raw/199806.txt`。题目指定的“人民日报 9801”对应 `raw/199801.txt`。其余月份是否纳入实验，留待后续确定。

## 保存结构

```text
data/
├── README.md
├── manifest.json   # 当前原始文件的编码、大小、行数、SHA-256 和控制字符记录
├── raw/            # 原始语料，保留原始内容
├── processed/task1/pd9801-v1/  # 任务一派生文章及审计，不提交
└── splits/task1/pd9801-v1/     # 任务一训练/验证/测试集，不提交
```

初始化时将文件从 `data/` 移入 `data/raw/`，原始内容保持不变。任务一已基于 1 月语料生成独立的派生数据及文章级划分，2—6 月未使用。具体规则、数量和校验值见 [任务一报告](../task1/reports/experiment.md)。

## 编码与格式

六份文件均为可严格解码的 UTF-8，无 BOM，无 `U+FFFD` 替换字符和 NUL。`raw/199803.txt` 首行有一处 `U+0016`，详见 [审计清单](../docs/corpus-inventory.md)；不在本次 1 月实验范围内。任务一只在派生文本中删除并审计控制字符，原文件保持不变。

语料包含行首编号、空格分词、词性与组合词标注，任务一已实现解析、正文还原和七类常用标点标签构造。派生数据不得覆盖原始文件；改变处理规则或划分须使用新的版本目录。

## 版本与分发

Git 仅跟踪本说明、`manifest.json` 和三个子目录的 `.gitkeep`，原始及派生语料不上传。克隆仓库后需自行提供六份文件，并核对清单中的文件名、大小和 SHA-256。

来源下载地址和授权信息尚未由用户提供，清单中以 `null` 表示未知，不推断或补造来源。项目 MIT 许可证不授予这些语料的使用或分发权。换源后需重新生成并审查清单，不能沿用旧文件的校验值。
