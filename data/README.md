# 数据目录

当前语料由用户换源提供，共六份，文件为 `raw/199801.txt` 至 `raw/199806.txt`。题目指定的“人民日报 9801”对应 `raw/199801.txt`。其余月份是否纳入实验，留待后续确定。

## 保存结构

```text
data/
├── README.md
├── manifest.json   # 当前原始文件的编码、大小、行数、SHA-256 和控制字符记录
├── raw/            # 原始语料，保留原始内容
├── processed/      # 未来的清洗与文本还原结果，目前为空
└── splits/         # 未来的训练/验证/测试划分，目前为空
```

本次只将用户提供的文件从 `data/` 移入 `data/raw/`，移动前后内容逐字节一致，没有清洗、转码、修复或生成训练样本。

## 编码与格式

六份文件均为可严格解码的 UTF-8，无 BOM，无 `U+FFFD` 替换字符和 NUL，使用 UTF-8 直接打开即可。`raw/199803.txt` 首行有一处 `U+0016` 控制字符，详见 [审计清单](../docs/corpus-inventory.md)。保留原始记录，待用户授权数据制备阶段后再制定处理规则。

语料包含行首编号、空格分词、`/n` 等词性标签和 `[词/标签 …]组合标签`，未来需解析这些标注后还原正文，不能把标注符号直接当作标点恢复标签。

## 版本与分发

Git 仅跟踪本说明、`manifest.json` 和三个子目录的 `.gitkeep`，原始及派生语料不上传。克隆仓库后需自行提供六份文件，并核对清单中的文件名、大小和 SHA-256。

来源下载地址和授权信息尚未由用户提供，清单中以 `null` 表示未知，不推断或补造来源。项目 MIT 许可证不授予这些语料的使用或分发权。换源后需重新生成并审查清单，不能沿用旧文件的校验值。
