## 微调设置

从 `google-bert/bert-base-chinese` 的预训练编码器开始，新增八类 token 分类头，更新全部参数；上游模型提交 `8f23c25b06e129b6c986331a13d8d025a92cf0ea`。通用中文 BERT 是主实验，古文 GuwenBERT 是对照，二者都在同一 CCLUE 划分上重新微调，没有直接使用现成标点模型。

每个 Unicode 字符独立编码，监督第一个 subtoken；后续 subtoken、特殊 token 和 padding 用 -100 忽略，空编码以 UNK 占位。窗口按实际 token 数装箱，最大 256（含 CLS/SEP），不重叠、不静默截断、不人为补句末。该规则便于将模型作为独立文件交给任务二，但与预训练整句分词不同，可能影响拉丁字符等输入。

seed=42，训练 3 轮，batch=32，评测 batch=64，BF16；AdamW 学习率 3e-05，weight decay=0.01，warmup=0.1，线性衰减、梯度裁剪 1.0，无类别加权或重采样。只依据开发集标点 micro-F1 保存最佳 checkpoint（epoch 3），训练完成后才运行测试集。未依据测试结果继续调参。

硬件 NVIDIA GeForce RTX 5070；Python 3.12.15，PyTorch 2.9.1+cu128，Transformers 4.57.6，CUDA 12.8。训练 26,890 窗，开发 4,074 窗，共 2,523 优化步。训练耗时 314.30 秒（含逐轮开发评测及导出，不含下载和预处理），峰值已分配/保留显存 4.51/7.07 GiB。时间边界已同步 GPU；PyTorch 显存指标不代表驱动总占用。

## 局限和交接

这是特定古籍集合上的单种子基线，不代表所有体裁上的质量。标点与引号/书名号为分开的上游任务，本次只训练七类标点，不恢复引号或原始排版。GuwenBERT 预训练使用殆知阁，而 CCLUE 是其衍生数据，存在预训练重叠风险；通用中文模型也不能保证完全没见过这些经典。两个模型的词表及预训练过程不同，差异不能仅归因为一个因素。

标准 Transformers 模型、tokenizer、labels.json、inference_contract.json 和参考预测可由任务二独立加载。任务一只有单窗演示；长文本滑窗、批量解码和性能对照属于任务二，当前未实施。任务二应优先使用主实验的模型；对照模型另存，不覆盖主模型。
