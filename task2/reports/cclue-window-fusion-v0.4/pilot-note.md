# 开发集初始实现测量与优化记录

日期：2026-10-17。本目录保存跨窗口概率融合初始实现的 11 个开发集条件、55 次正式测量及源码快照，不包含测试集评价。

在分析聚合开销时发现，中心权重函数每窗将整个文档 token 前缀列表转换为数组，等权融合也调用了该函数。此处理会产生与全文长度相关的重复成本，融合公式本身不需要该操作。

后续实现改为只转换窗口范围内的前缀索引，等权方案直接使用全一权重；模型、窗口、概率精度、加权公式及选择规则均保持一致。优化后使用独立编号 `cclue-window-fusion-v0.4-optimized`，完整复测开发集，再锁定参数做测试。两次开发集的预测与概率指纹逐条件比较，避免将实现优化混入质量变化。

本目录的结果、参数记录与源码快照原样保留。初始代码位于 `code/outputs/task2/source-snapshots/cclue-window-fusion-v0.4/`，当前代码对应优化后的版本。原始指标及五次计时见 [development.json](development.json)，汇总见 [development.csv](development.csv)。最终实验使用优化后的独立目录。
